# Mate Magic Budget

**🚧 Work in progress — check back soon.**

Mate Magic Budget by Effecet is a self-hosted, single-user budgeting app. It
pulls transactions from Canadian banks through [Plaid](https://plaid.com),
keeps them in your own Postgres database, and shows monthly spending,
budgets and trends in a small web app you run at home with Docker.

The code is being prepared for release. This repository holds only this
note for now: no code, no releases, and nothing to install yet.

## Planned

- Runs anywhere with `docker compose up`, including a Raspberry Pi
- A demo mode with synthetic data, and a live demo on GitHub Pages
- Bank tokens encrypted at rest; LAN or localhost access only, never
  exposed to the internet
- Step-by-step guide to getting your own Plaid keys
